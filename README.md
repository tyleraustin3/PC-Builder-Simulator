# PC Builder Simulator

A PC building and business simulation game made with Python and Pygame.

## Features
- Build custom PCs using different components
- Buy and sell completed builds
- Earn passive income from your PC inventory
- Save your game progress
- Music volume and mute settings

## How to Play

### Download
Download the latest Windows Setup exe from the [Releases](../../releases) page.

## Uninstall
Open Windows Run (Windows + R)
Type "%localappdata%" and hit enter.
Then scroll and find the "Programs" file and open it.
Then open the "Computer Building Simulator" file.
Finally run the "unins000" application and follow the steps.

### Run from Source
1. Install Python.
2. Install Pygame with `py -3.13 -m pip install pygame`.
3. Run `py -3.13 main.py`.
