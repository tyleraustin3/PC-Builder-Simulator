# PC Builder Simulator

A PC building and business simulation game made with Python and Pygame.

## Features
- Build custom PCs using different components
- Buy and sell completed builds
- Earn passive income from your PC inventory
- Save your game progress
- Music volume and mute settings

## How to Play

### Download
Download the latest Windows executable from the [Releases](../../releases) page.

### Run from Source
1. Install Python.
2. Install Pygame with `py -3.13 -m pip install pygame`.
3. Run `py -3.13 main.py`.
